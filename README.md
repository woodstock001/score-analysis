# 成绩分析

**线上：** https://woodstock001.github.io/score-analysis/
**代码：** https://github.com/woodstock001/score-analysis

成都中考 710 分制 · 初中三年成绩追踪与诊断。纯静态网页，数据只存在你自己的浏览器和你自己的 Supabase 项目里，不经过任何第三方后端。

## 一、直接开始用

打开网页就是可用的，不需要注册。

1. **录入** → 填考试名称、日期，各科分数（满分可改）
2. 保存后自动跳到**分析**，出单次体检、目标差距、学科诊断、提分空间
3. 录满 2 次出趋势线，录满 3 次出预警

预置了两个学生：QQ（初一）、汤圆（四年级，预留）。在「学生」页改年级就能启用。

## 二、云备份（可选）

不配置也能用，但换设备或清缓存会丢。配置后数据存在你自己的 Supabase 里，多设备同步。

1. 打开 [supabase.com](https://supabase.com) 注册，新建项目（免费版够用，4000 行数据不到 1MB）
2. 项目里 → **SQL Editor** → 新建查询 → 粘贴 `supabase.sql` 全部内容 → Run
3. 项目设置 → **API** → 复制 `Project URL` 和 `anon public` key
4. 回到网页「设置」页，填进去，用邮箱注册账号，点「上传到云端」
5. 换设备时登录，点「从云端恢复」

> 如果注册后登录提示邮箱未确认：Supabase 后台 Authentication → Providers → Email → 关掉 "Confirm email"。

## 三、部署到 GitHub Pages

1. 在 GitHub 新建仓库（如 `score-analysis`），Public
2. 把本目录除 `.coze` 外的所有文件传上去（网页上传或 `git push`）
3. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)` → Save
4. 等 1 分钟，访问 `https://你的用户名.github.io/score-analysis/`

纯静态，无构建、无依赖、无 CDN，任何静态托管都能跑（Cloudflare Pages、Vercel、对象存储都行）。

## 五、分析口径（重要）

**分值**：成都现行 710 分制（成招考委〔2026〕5号）。语文/数学/英语各 150、物理 70、化学 50、体育 60、道法/历史/地理/生物各 20（等级 A20/B16/C12/D8 折算）。分值表可改，若成都出台 750 方案，改 `config.js` 里的 `zk` 字段即可，历史数据不受影响。

**得分率优先**：所有横向对比用得分率（得分÷满分），不用原始分。语文 120 和数学 120 不等值，跨科跨年级只有得分率可比。

**位次优先**：目标校追踪以录取位次为主。2025 年 630 分对应位次 3345，2026 年同分对应 2808，分数线每年平移，位次才稳定。

**降级规则**：没录排名/均分就跳过对应指标，不报错、不用 0 填、不猜。缺什么，那张卡片会说明缺什么。

**外推分的边界**：初一缺物理、化学、体育，外推中考分是"假设未考科目保持同等水平"的参考值，不是预测。页面会标覆盖度和置信度。初三全科齐了才有完整折算。

**单次差不叫弱科**：单次下滑叫失常，连续 3 次才算弱科。

## 六、数据年份

目标校录取数据为 **2026 年**（来源：成都市教育考试院 2026-07-10 录取公告、成华区各校 2026 统招线公告）。每年 7 月更新。标注 `B 级` 的是咨询线，不是录取线，仅供参考。

## 七、隐私

- 数据默认只在浏览器 localStorage
- 配置 Supabase 后，数据只进你自己的项目，RLS 保证只有你的账号能读
- 没有第三方统计、没有埋点、没有外部请求（除你自己配置的 Supabase）
